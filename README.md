# Agent Monitor / Orchestra

Enterprise AI agent monitoring and governance app.

The project has two apps:

```text
backend/   FastAPI API, WebSocket event stream, Postgres/Timescale persistence
frontend/  React + Vite dashboard
```

## What This App Does

- Onboard Langfuse-backed AI agents.
- Import Langfuse traces/observations into local telemetry tables.
- Monitor runs, events, costs, tokens, latency, errors, and trace payloads.
- Maintain organization master data in Settings.
- Map agents to organization hierarchy nodes.
- Show an Organization Graph with cumulative cost/token/execution roll-ups.

## Environment

Backend reads `backend/.env`.

Default local values:

```env
REDIS_URL=redis://localhost:6379/0
REDIS_CHANNEL=agent_events
DATABASE_URL=postgresql://user:pass@localhost:5432/agent_monitor
WEBSOCKET_ORIGINS=*
AGENT_SECRET_KEY=
LOGIN_ALLOWED_EMAILS=
LOGIN_OTP_MINUTES=10
LOGIN_SESSION_HOURS=12
LOGIN_SHOW_DEV_OTP=true
LOGIN_DEV_OTP_ENABLED=false
LOGIN_DEV_OTP=123456
SMTP_HOST=
SMTP_PORT=587
SMTP_USERNAME=
SMTP_PASSWORD=
SMTP_FROM_EMAIL=
SMTP_USE_TLS=true
```

`AGENT_SECRET_KEY` can be left blank for local development. The backend will create `backend/.agent_secret.key`.

OTP login shows the OTP on the login screen while `LOGIN_SHOW_DEV_OTP=true`, which is useful for local development. To allow a fixed development OTP, set `LOGIN_DEV_OTP_ENABLED=true`; the default fixed value is `123456`. To send OTPs by email, set `SMTP_HOST` and `SMTP_FROM_EMAIL`; set `SMTP_USERNAME` and `SMTP_PASSWORD` if the mail server requires authentication. Use `LOGIN_ALLOWED_EMAILS` as a comma-separated allowlist when you want to restrict who can sign in. Set `LOGIN_SHOW_DEV_OTP=false` and `LOGIN_DEV_OTP_ENABLED=false` for production.

For stable encrypted credentials across machines, generate and set a fixed key:

```powershell
python -c "from cryptography.fernet import Fernet; print(Fernet.generate_key().decode())"
```

## Add An Agent By API

Agent ID is generated by the backend. Do not send `agent_id` on create.

```powershell
$payload = @{
  display_name = "Translation Agent"
  provider = "langfuse"
  base_url = "https://hipaa.cloud.langfuse.com"
  public_key = "pk-lf-..."
  secret_key = "sk-lf-..."
  profile = @{
    onboarding_status = "Draft"
  }
  node_mappings = @()
} | ConvertTo-Json -Depth 8

Invoke-RestMethod -Method Post `
  -Uri "http://127.0.0.1:8001/agents" `
  -ContentType "application/json" `
  -Body $payload
```

Import Langfuse data:

```powershell
Invoke-RestMethod -Method Post `
  -Uri "http://127.0.0.1:8001/agents/{agent_id}/import-langfuse" `
  -ContentType "application/json" `
  -Body '{"limit":100,"max_pages":5}'
```

## Organization Setup Flow

1. Open `Settings`.
2. Create node types if needed.
3. Create organization hierarchy nodes.
4. Open `Agents`.
5. Edit/onboard an agent.
6. Select a Primary Organization Node in Business Mapping.
7. Open `Organization Graph` to see hierarchy, mapped agents, and cumulative metrics.

Organization hierarchy is created only in Settings. Onboarding and Graph only consume existing hierarchy data.

## Organization Graph

The graph consumes:

- Settings organization nodes
- Agent registry
- Agent node mappings
- Runtime metrics from `agent_events`

Roll-up rules:

- Sum: cost, tokens, executions, API calls, runtime duration
- Weighted average: latency, success rate, error rate

`GET /organization-graph` returns:

```json
{
  "nodes": [],
  "edges": [],
  "metrics": {},
  "filters": {},
  "layout": {}
}
```

## Troubleshooting

Port already in use:

```powershell
Get-CimInstance Win32_Process |
  Where-Object { $_.CommandLine -match 'uvicorn main:app|vite --host 127.0.0.1 --port 5179' } |
  Select-Object ProcessId,CommandLine
```

Stop a process:

```powershell
Stop-Process -Id <PID> -Force
```

Database not connecting:

```powershell
cd backend
docker compose ps
docker compose up -d
```

Frontend cannot reach backend:

- Confirm backend health: `http://127.0.0.1:8001/health`
- Confirm frontend is on `http://127.0.0.1:5179`
- Check `frontend/src/config.js`

Langfuse import returns unauthorized:

- Edit the agent.
- Re-enter the Langfuse public key and secret key.
- Save changes.
- Run Import Langfuse again.
