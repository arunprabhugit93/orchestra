# Backend

FastAPI backend for Agent Monitor.

For full project setup, read the root `README.md`.

## Local Backend Setup

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements.txt
Copy-Item .env.example .env
docker compose up -d
python -m uvicorn main:app --host 127.0.0.1 --port 8001
```

Health check:

```powershell
Invoke-RestMethod http://127.0.0.1:8001/health
```

## Required Services

`docker-compose.yml` starts:

- TimescaleDB/Postgres on `localhost:5432`
- Redis on `localhost:6379`

Default database URL:

```text
postgresql://user:pass@localhost:5432/agent_monitor
```

## Main APIs

```text
GET  /health
POST /auth/request-otp
POST /auth/verify-otp
GET  /auth/me
GET  /agents
POST /agents
PUT  /agents/{agent_id}
POST /agents/{agent_id}/import-langfuse
GET  /runs
GET  /runs/{run_id}/events
GET  /settings/organization-nodes/hierarchy
GET  /organization-graph
WS   /ws/events
```

## Notes

- Agent IDs are generated by the backend.
- OTP login shows a development OTP on screen unless SMTP is configured with `SMTP_HOST` and `SMTP_FROM_EMAIL`.
- Langfuse keys are encrypted before storage.
- Organization hierarchy is managed through Settings APIs only.
- Agent-to-organization mapping is stored in `agent_node_mapping`.
- Graph roll-ups are generated by `services/organization_graph.py`.
